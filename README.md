# 📢🎉BoTech.SharpStudio
## What is BoTech.SharpStudio?
+ BoTech.SharpStudio evolved from the idea of ​​BoTech.DesignerForAvalonia. The old designer was far too focused on the Avalonia framework. During the second development phase, it became clear that in-depth code analysis was necessary to simulate bindings, etc. Therefore, I'm starting this project from scratch...
+ The goal of BoTech.SharpStudio is to be a cross-platform and powerful IDE for C#.
+ It is built using c# and avaloniaUI.
+ It is still in early development, so expect bugs and missing features.
+ It is open source and free to use.

It is licensed under the [MIT](https://github.com/BoTech-Development/BoTech.SharpStudio/blob/master/LICENSE.txt) license.

## Development stages 
1. Basic IDE features (Syntax highlighting, Solution explorer, Build and Run)
	+ 1.1. Solution Explorer
	+ 1.2. Code editor
    + 1.3. Syntax Highlighting in the code editor.
	+ 1.4. Bulding and Running C# projects.
	+ 1.5. Debugger (Breakpoints, Step over, Step into, Step out)
2. Integration of the Designer for avalonia
